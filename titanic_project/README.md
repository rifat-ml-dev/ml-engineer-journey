# ml-engineer-journey
My journey toward becoming a Machine Learning Engineer. Projects, experiments, backend development, and continuous learning.


## Titanic Survival Prediction:
- Built an end-to-end machine learning pipeline using the Titanic dataset.

## What I did:
- Data cleaning and missing value handling
- Feature encoding
- Train-test split
- Logistic Regression model training
- Model evaluation (accuracy, precision, recall, F1-score)
- Feature scaling experiment
- Decision Tree comparison
- Overfitting analysis
- 5-fold cross validation

## Results:
- Logistic Regression Accuracy: 79.8%
- Cross Validation Accuracy: 79.3%

## Key Learning:
- Data leakage prevention
- Model interpretability
- Overfitting detection
- Experiment tracking with Git
